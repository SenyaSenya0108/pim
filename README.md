# PIM

## Стек приложения
**ЯП: PHP 8.4  
Фреймворки: Symfony 7.3, Api Platform 4.2  
БД: PostgreSQL 16  
Веб-сервер: Caddy  
Инструменты: deptrac  
Инфраструктура: docker**  


## Архитектура проекта
_Приложение строится как модульный монолит. Модульность обеспечивается за счет разделения модулей по предметной области.
Для того чтобы создать новый модуль, нужно добавить в config/packages/doctrine.yaml в mappings настройки нового модуля  
и в config/routes.yaml настройки новых контроллеров(если они нужны)
Для проверки соблюдения границ модулей используется deptrac_


## Начало работы
_Запустить сборку приложения, войти в контейнер с php и применить миграции_  

## Консольные команды

### Запустить сборку приложения
```bash
    docker compose up -d
```

### Применить миграции
```bash
    php bin/console d:m:m
```

### Генерация ключей JWT 
```bash
  php bin/console lexik:jwt:generate-keypair
```

### Запустить deptrac
```bash
    vendor/bin/deptrac 
```

### Зайти в контейнер
```bash
    docker exec -it <название контейнера> sh
```
